## Use with Birthdays

Install the icon from the Hub or upload this GIF using the **Icons** tab in the AWTRIX web interface. Keep the file name `birthdaycake-2.gif` and set **Apps → Birthdays → ⚙ → Icon ID** to **`birthdaycake-2`**, without the extension.

The older default `7020` is a different local icon ID. The app does not automatically change that setting or download the new icon. You can still use another installed 8×8 icon, or leave the setting empty for the built-in cake drawing.
