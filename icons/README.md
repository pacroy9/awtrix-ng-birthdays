## Use with Birthdays

Install the icon from the Hub or upload this GIF using the **Icons** tab in the AWTRIX web interface. Keep the file name `birthdaycake-2.gif` and set **Apps → Birthdays → ⚙ → Icon ID** to **`birthdaycake-2`**, without the extension.

Version **4.6.4** uses `birthdaycake-2` as the default and declares it with `# @icons`, allowing the Hub to install it with the app when the device's Hub connection is configured. Updates preserve saved icon settings: if your app still uses the older ID `7020`, change **Icon ID** to `birthdaycake-2` and save. You can still use another installed 8×8 icon, or leave the setting empty for the built-in cake drawing.
